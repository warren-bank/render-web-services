### [Render Web Services](https://github.com/warren-bank/render-web-services/tree/main)

Assorted collection of Web Services hosted on [free tier at render.com](https://render.com/docs/free):

* [hauk](https://github.com/warren-bank/render-web-services/tree/hauk)
  - PHP backend for self-hosted location sharing service
* [hls-proxy](https://github.com/warren-bank/render-web-services/tree/hls-proxy)
  - Node.js server to proxy HLS video streams
* [libre-translate](https://github.com/warren-bank/render-web-services/tree/libre-translate)
  - Python language translation API and web-app built on top of [Argos Translate](https://github.com/argosopentech/argos-translate)
* [maddy-email](https://github.com/warren-bank/render-web-services/tree/maddy-email)
  - Golang e-mail server
  - access is restricted by hosting [limitations](https://github.com/warren-bank/render-web-services/tree/maddy-email#limitations)
* [ntfy](https://github.com/warren-bank/render-web-services/tree/ntfy)
  - Golang HTTP-based pub-sub notification service
  - clients are available for [web](https://warren-bank-ntfy.onrender.com/) and [mobile](https://github.com/binwiederhier/ntfy-android)
